1. date
------------------------------
Purpose: Print the date and time
Syntax:  date [options] [+format] [date]

Example: $ date
Output:  Mon Jul 28 9:59 IST 2025

Options:
  %a  : Print abbreviated weekday (Mon)
        eg: $ date +%a        -> OP: Mon
  %A  : Print full weekday (Tuesday)
        eg: $ date +%A        -> OP: Monday
  %b  : Print abbreviated month name (Jul)
        eg: $ date +%b        -> OP: Jul
  %B  : Print full month name (January)
        eg: $ date +%B        -> OP: July
  %c  : Prints country-specific date and time format
        eg: $ date +%c        -> OP: Mon Jul 28 20:58:46 2025
  %D  : Print date in the format %m/%d/%y
        eg: $ date +%D        -> OP: 07/28/25
  %j  : Julian day of year (001-366)
        eg: $ date +%j        -> OP: 209
  %n  : Insert a new line
        eg: $ date +"Date is %D %n Time is %T"
        OP: Date is 07/28/25
            Time is 21:14:58
  %p  : Prints string to indicate a.m. or p.m.
        eg: $ date +%p        -> OP: PM
  %T  : Prints time in the format %H:%M:%S
        eg: $ date +%T        -> OP: 21:18:54
  %t  : Shows tab space
        eg: $ date +"Date is %D %t Time is %T"
        OP: Date is 07/28/25    Time is 21:18:54.
  %V  : Prints week number in year (01-52); Start week on Monday.
        eg: $ date +%V        -> OP: 31

2. who
------------------------------
Purpose: To list the names of users currently logged in, their terminal,
         the time they have been logged in & the name of the host from
         which they have logged in.
Syntax:  who [options] [file]

Example: $ who -uH
Output:
NAME    LINE   TIME       IDLE  PID  COMMENT
hiose   ttyp3  Jul 10 11:08  .   4578

Options:
  am i     : Prints the username of the invoking user. The 'am' and 'i'
             must be space separated.
             eg: $ who am i
  -b       : Prints time of last system boot.
             eg: $ who -b
  -d       : Prints dead processes.
             eg: $ who -d
  -H       : Prints column headings above the output.
             eg: $ who -H
  -i       : Include idle time as HOURS:MINUTES. An idle time of . 
             indicates activity within the last minute.
             eg: $ who -i
  -m       : Prints same as who am i
             eg: $ who -m
  -q       : Prints only the usernames and the user count/total no of
             users logged in.
             eg: $ who -q
  -T, -w   : Include user's message status in the output
             eg: $ who -T
                 $ who -w

3. echo
------------------------------
Purpose: Prints the given input string to standard output.
Syntax:  echo [options] [string]

Example: $ echo "Hi, I am Savani"
Output:  Hi, I am Savani

Options:
  -n : do not output the trailing newline
       eg: $ echo -n "This is newline."
       OP: This is newline
  -e : Enable interpretation of the backslash-escaped characters listed
       below.
       eg: $ echo -e "hscripts\b Hiox\b India"
       OP: hscriptsHioxIndia
  -E : Disable interpretation of those sequences in strings.
       eg: $ echo -E "hscripts\b Hiox\b India"

  Without -E, the following sequences are recognized and inserted:
  \NNN : Prints the character whose ASCII code is NNN (octal).
         eg: $ echo -e "\067"      -> Output: 7
  \a   : Alert
         eg: $ echo -e "\a"
  \\   : Backslash
         eg: $ echo -e "\\"
  \b   : Backspace
         eg: $ echo -e "Hi\bI'm\bSavani"   -> OP: HiI'mSavani
  \c   : Used to suppress trailing newline
         eg: echo -e "Hello\c"
             echo "World"
         OP: HelloWorld
  \f   : Used to form feed
         eg: echo -e "Hello World\f This is Linux Programming"
         OP: Hello World
             This is Linux Programming.
  \n   : Used for newline
         eg: $ echo -e "Hello \n World"
         OP: Hello
             World
  \r   : Carriage return. Returns the cursor to beginning of line
         eg: $ echo -e "Hello \r World"
         OP: World
  \t   : Horizontal tab
         eg: $ echo -e "Hello \t World"
         OP: Hello   World
  \v   : Vertical tab
         eg: $ echo -e "Hello \v World"
         OP: Hello
                 World

Aim: Write pattern matching commands of Linux with options and example.

------------------------------
1. grep
------------------------------
Purpose: Used for searching for a pattern
Syntax:  $ grep [options] patterns [filenames]

Example: $ grep "sales" emp.lst
Output:
2233 a.k. shukla    g.m      sales 12/12/52 6000
1006 chanchal singh director sales 03/09/38 6700
1265 s.n. dasgupta  manager  sales 12/09/63 5600
2476 anil aggarwal  manager  sales 01/05/59 5000

Options:
  -i : Ignores cases for matching
  -v : Doesn't display lines matching expression.
  -n : Displays line numbers along with lines
  -c : Displays count of number of occurrences
  -l : Displays names of filenames only.
  -f : Takes pattern from file, one per line.

Special characters used with grep:

i) [ ]
   Purpose: Lets you specify group of characters within a pair of
             rectangular brackets.
   Example: $ grep "[aA]g[ar]wal" emp.lst
   Output:
   3564 sudhir Agarwal executive personnel 07/06/47 7500
   0110 V.K. agrawal   g.m       marketing 12/31/40 9000

ii) *
   Purpose: Used to match zero or more occurrences of the immediately
             preceding character.
   Example: $ grep "[aA]gg*[ar]wal" emp.lst
   Output:
   2476 anil aggarwal manager sales     05/1/59 5000
   3564 sudhir Agarwal executive personnel 07/06/47 7500
   0110 V.K. agrawal g.m marketing 12/31/40 9000

iii) .
   Purpose: It matches a single character.
   Example: $ grep "j.*saxena" emp.lst
   Output:
   2345 j.b.saxena g.m marketing 03/12/45 8000

iv) ^
   Purpose: Used for matching pattern at the beginning of a line.
   Example: $ grep "^2" emp.lst
   Output:
   2233 a.k. shukla g.m sales 12/12/52 6000
   2365 barun sengupta director personnel 05/11/47 7800
   2476 anil aggarwal manager sales 05/11/59 5000

v) (I, (and))
   Purpose: Used for matching multiple patterns
   Example: $ grep -E 'sengupta|dasgupta' emp.lst
   Output:
   2305 barun sengupta director personnel 11/05/47 7800
   1265 s.n. dasgupta  manager  sales     12/09/63 5600

------------------------------
sed
------------------------------
Purpose: Combines the work of several filters
Syntax:  $ sed options 'address action' file(s)

Example: $ sed '2q' emp.lst
Output:
2233 a.k. shukla g.m sales      12/12/52 6000
9876 jai sharma director production 03/12/50 7000

Options:
  -p : Print command to display lines
  -q : To quit

1. /   -- Context addressing, lets us specify one or two patterns to
          locate lines.
   Example: $ sed -n '/director/p' emp.lst
   Output:
   9876 jai sharma    director production 03/12/50 7000
   2365 barun sengupta director personnel 05/11/47 7800
   1006 chanchal singh director sales     09/03/48 6700

2. Text editing:

   D (i, a, c)
   Purpose: Used to
       i = insert the text
       a = append
       c = change.
   Example: $ sed 'i\
   > #include <stdio.h>\
   > #include <unistd.h>\
   > 'foo.c > $$

   d
   Purpose: Used for deleting lines.

   Substitution (s)
   Purpose: Lets us replace a pattern in its input with something else.
   Syntax:  [address] s/expression1/exp2/flags.
   Example: $ sed 's/1:/ ' emp.lst | head -n 2
   Output:
   2233: a.k. shukla g.m sales      12/12/52 6000
   9876: jai sharma  director production 12/03/50 7000

   \1  -- sed "remembers" the scanned pattern & stores it in \1.
   Example: $ sed -n '/marketing/s/director/member/p' emp.lst
   OP:

i) Default behaviour of awk
   By default AWK prints every line of data for the specified line.
   Example: $ awk '{print}' emp.txt
   Output: (prints all lines exactly as above)

ii) To print the lines which matches with the given pattern

   $ awk '/manager/ {print}' emp.txt
   Output:
   ajay  manager account 45000
   varun manager sales   50000
   amit  manager account 47000

iii) For splitting a line into fields:

   $ awk '{print $1, $4}' emp.txt
   Output:
   ajay   45000

   varun  50000
   amit   47000
   tarun  15000
   deepak 23000

CONDITIONAL STATEMENT

1. if statement
   To check whether a number is positive or not.

   $ awk 'BEGIN {
       num = 10; if (num > 0) printf "%d is positive number.\n", num
   }'

   Output: 10 is positive number.

2. if-else
   To check whether a number is even or odd.

   $ awk 'BEGIN {
       num = 12; if (num % 2 == 0)
       printf "%d is even, num";
       else
       printf "%d is odd, num" }'

   Output: 12 is even number.

LOOP STATEMENTS

1. For loop
   To print square of first 6 numbers

   $ awk 'BEGIN { for (i=1; i<=6; i++) print "Square of", i, "is", i*i; }'

   Square of 2 is 4
   Square of 3 is 9
   Square of 4 is 16

   Square of 6 is 36

   To print 1 to 5 numbers

3. Do-while loop

   $ awk 'BEGIN { i=1; do {print i; ++i} while (i<6) }'

   5

4. Write a shell program to find fibonacci series

echo "Fibonacci Series"
echo "Enter the number"
read n

if (( n <= 0 )); then
  echo "Please enter a positive no. of terms"
elif (( n == 1 )); then
  echo "Fibonacci Series: 0"
else
  a=0
  b=1
  echo "Fibonacci Series:"
  echo -n "$a "
  echo -n "$b "
  for (( i=2; i<n; i++ )); do
    next_term=$((a+b))
    echo -n "$next_term "
    a=$b
    b=$next_term
  done
  echo ""
fi
